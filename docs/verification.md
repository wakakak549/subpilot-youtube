# 第一版验收记录

日期：2026-10-15（北京时间）。版本：`0.1.6`。

以下为开发时的验收记录。`artifacts/` 中的接口诊断与截图仅保存在本地，不随公开源码分发；自动化检查可按 README 中的命令重跑。

## 自动化验证

核心验证使用 Node.js，浏览器验证使用独立配置的本机 Chrome 和真实加载的 MV3 扩展。字幕网页与 AI 响应使用测试数据，字幕消息确实跨越 MAIN、isolated、service worker 三个运行环境。

本次结果：50 项核心测试、24 项浏览器集成检查全部通过，浏览器集成检查未发现页面脚本错误。首版曾通过 18 项核心测试和 17 项浏览器检查。

已验证的主要场景：

- JSON3、旧式 XML、srv3 XML 解析，空字幕事件处理，时间重叠裁剪与分组。
- 播放位置与有限预取，暂停不启动新翻译，跳转优先翻译新位置。
- 缓存命中，接口地址与目标语言变化导致缓存失效，容量淘汰和清空。
- 缺行只重试缺失编号；空 JSON、限流和网络超时有上限；鉴权与配置错误只发一次。
- 请求取消后不再重试或写入缓存，过期字幕和译文不能污染新视频。
- 相同段数的字幕内容替换仍能更新。
- 关闭翻译恢复原生字幕，API 失败恢复原生字幕，手动重试能恢复。
- 正常待翻译时，播放器右上角的进度徽标为空且不可见；API 报错时仍显示错误，重试恢复后隐藏。
- 模型请求保留 `gpt-6.1-sol`，使用低推理强度且不发送 `temperature`。
- 本地接口可以不填密钥；公开配置消息不包含密钥；同步存储没有配置或密钥。
- 中文设置、弹窗显示模式切换、连接测试、图标资源和缓存管理。
- 桌面、窄屏与全屏截图，横向溢出和长字幕布局检查。
- 设置、内容脚本、后台校验和 API 均允许 100 段；120 段测试字幕按 100 段和 20 段两次返回并完整缓存。
- 预取最长 600 秒，仍遵守窗口范围，已有较小段数配置不被改写。
- 本地回环地址自动补 `/v1`，模型列表获取、去重及排除嵌入模型，错误响应遮盖密钥。
- 本地模型使用 `max_tokens`，保留可选 JSON Schema，不发送 OpenAI 推理参数。
- 接口类型可手动指定，局域网 LM Studio 的地址和请求格式正确，本地 OpenAI 代理可保留 OpenAI 参数。
- Hy-MT2-1.8B/7B 自动采用模型卡推荐的纯文本逐行提示，使用 `temperature=0.7`、`top_p=0.6`、`top_k=20`、`repetition_penalty=1.05`，不发送严格 JSON Schema。
- Hy-MT2 编号译文解析会过滤模型额外的编号外文本，支持同一行中的多个编号；序号只用于接口内部匹配。无编号返回必须与输入行数相同，编号或条数缺失时整批逐条重译，防止模型先合并字幕再重排后续编号。普通 JSON 模型继续保留可靠结果，只重试缺失部分。
- “每个输入编号必须返回一行”等旧版说明，以及当前请求的指令回显，在纯文本、编号列表和 JSON 输出中均会被拒收。混合响应保留可靠编号的正常译文，回显混入无编号输出时不猜测对应位置，避免错位。
- 在编号完整的批次中，被拒收的条目只重试对应字幕；编号不完整时整批重译。单条使用不带编号或上下文的翻译模板，独立请求最多尝试 3 次；普通 JSON 模型也会检查实际请求指令的回显。
- 单条模板保留年份、小数、时间及正文的数字列表；正常字幕确实包含上述格式说明原文时保留，编号被重置为连续序号时也能正确映射。
- 缓存版本从 4 升到 5，旧译文不再复用，API 配置保留。缓存读取、写入和页面接收时均校验译文相对源字幕的长度，拒收明显膨胀的段落。
- 从使用者真实 Chrome 缓存和 LM Studio 日志找到截图中的同一段异常文本，作为回归数据。Chrome 检查让批量与单条重试均返回该段落，确认异常内容始终没有显示或缓存，正常重试后可恢复。
- 真实模型“20 条输入、18 个编号、后续语义整体错位”的返回作为另一项回归数据，要求整批拒收；100 条合并响应通过 1 次批量和 100 次独立请求完整恢复，不再受旧的 24 次请求预算提前截断。
- Chrome MV3 后台在 31 秒慢响应中仍完成请求；超时默认 120 秒，可调整为 15–300 秒。

测试输出与截图保存在 `artifacts/`。测试里的“译文”是本地服务生成的示例，不证明真实翻译质量。

## LM Studio 实测

0.1.6 检查时，本机 `http://localhost:1234/api/v0/models` 确认 `hy-mt2-7b` 已加载，窗口为 64000。使用当前已加载模型，没有加载或切换其他模型。

截图中的英文单条请求约 0.55 秒返回“主要目标。如果确实不会让SCV来指挥Reaper的话，那就还有……”，未混入后续地图、指挥中心或补给线内容。随后将这条原文与 19 条构造的游戏解说字幕一起发送，真实模型再次合并并重排编号；新版拒收了该批次，并发出 20 次独立请求，约 8.34 秒恢复全部 20 条。检查了前四条的对应语义，未再沿用错位编号；重复请求命中 20 条缓存，没有再次调用模型。记录在 `artifacts/merged-real-model-results.json`。

只有首条英文来自截图转录，后续 19 条是构造的测试输入，不能当作恢复了使用者视频的完整原文。这是接口层真实模型检查；本轮没有在使用者日常 Chrome 中自动重载扩展或播放原视频。长度检查用于识别明显异常，不代替语义质量评估。

### 此前 0.1.5 的记录

0.1.5 检查时，本机接口返回所有模型均为 `not-loaded`，没有发起会触发模型加载的生成请求。该轮回显修复使用确定的异常响应做核心与 Chrome 集成回归。

### 此前 0.1.4 及更早版本的记录

本机服务：`http://localhost:1234/v1`。`/api/v0/models` 确认 `hy-mt2-7b` 已加载；模型列表共提供 5 个文本模型，另一个嵌入模型被排除。检查没有加载其他模型，也没有修改日常 Chrome 配置。

随后加载了 `hy-mt2-7b`（Q4_K_M）复现用户反馈。旧版严格 JSON 请求返回约 9.8 秒的长串自我修正内容，其中混有 `"}]}`、括号和重复提示词；这不是字幕文本，而是模型在不合适的结构化输出约束下产生的格式噪声。

修复后的真实请求使用 Hy-MT2 模型卡推荐的纯翻译提示。20 条英文字幕由扩展请求实际返回，约 3.4 秒完成，20 个编号全部解析，译文示例为“你好，世界。”、“请打开字幕。”，没有 `"}]}` 或其他尾部字符。可用 `$env:YTAI_LOCAL_MODEL = 'hy-mt2-7b'; node tests/lmstudio-smoke.mjs` 重跑设置页连接检查。

修复前复现：填写裸地址 `http://localhost:1234` 会请求 `/chat/completions`，LM Studio 返回 HTTP 200 的错误对象，旧版却提示“模型没有返回文字译文”。带 `/v1` 的地址使用当前已加载模型可以正常翻译。当前 LM Studio 还会将不匹配的模型名回退到已加载模型，因此不能把默认 `gpt-6.1-sol` 未出现在列表中直接认定为本次连接失败原因。

此前 LM Studio 1.8B 修复验证：

- 裸地址自动规范化为 `http://localhost:1234/v1`，真实模型列表读取成功。
- 使用扩展实际请求模块翻译 12 段英文字幕，约 0.9 秒返回全部编号。
- 单次翻译 100 段英文测试字幕，约 8.2 秒返回全部 100 个编号，没有缺失；严格 JSON 输出保持开启。
- 独立 Chrome 加载真实扩展，通过设置页获取模型、保存配置、测试连接，返回“连接成功 · 你好，世界。”，没有页面脚本错误。

以上延迟仅反映本机已加载的 1.8B 模型和这些测试字幕，不代表其他模型或真实视频的持续播放表现。浏览器记录和截图：`artifacts/lmstudio-browser-results.json`、`artifacts/lmstudio-connection.png`。可用 `node tests/lmstudio-smoke.mjs` 重跑浏览器连接检查。

## 首版真实 YouTube 检查

视频：https://www.youtube.com/watch?v=arj7oStGLkU

真实页面加载与视频播放正常，能发现字幕轨，插件覆盖层也能显示读取状态。但本次独立浏览器会话中，英语和中文字幕 `/api/timedtext` 请求返回 HTTP 200、响应长度 0，原生字幕没有出现。页面提供的文字记录参数发起的检查请求返回 `FAILED_PRECONDITION`。

这项首轮独立会话检查**未通过完整字幕翻译验收**。插件正确保留原生显示，25 秒后显示“字幕暂时无法读取”，且没有向模拟 AI 服务发出字幕翻译请求。之后使用者反馈扩展可用，并提出每次最多 10 段和 LM Studio 连接问题，本次更新针对这些反馈。使用者反馈与上述独立测试会话的结果分别保留。

相关记录：`artifacts/youtube-live-results.json`、`artifacts/youtube-live.png`。本次没有调用真实 OpenAI API，因此 `gpt-6.1-sol` 的实际翻译质量、响应延迟及账号权限仍待配置后验证。

## 交付状态

提供 `0.1.6` 安装包、源码、依赖锁文件、安装说明与自动化检查。没有更改用户日常 Chrome 的配置或缓存数据库，没有发布到扩展商店，没有调用收费 AI 接口。本轮读取该扩展缓存、对照本地模型日志，并调用已加载的 Hy-MT2 完成上述接口检查；重新加载扩展后，旧译文缓存会自动失效。

正式验收还需要在能正常显示 YouTube 原生字幕的浏览器会话中，使用实际 API 对人工字幕、自动字幕和连续切换的视频完成播放验证。
